# ADR-0005 · Canva en el MVP

- Estado: Aceptado
- Fecha: 2026-10-05

## Contexto
El usuario quiere diseñar las piezas impresas en Canva.

## Decisión
MVP: export SVG/PDF y plantillas propias listas para importar en Canva. La integración con Canva Connect API pasa a Futuro.

## Alternativas descartadas
Integrar Canva Connect desde el inicio.

## Consecuencias
MVP más simple; sin dependencia de aprobación de app en Canva.
